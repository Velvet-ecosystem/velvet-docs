# Resource-Abuse Test Pack

A valid organ can still harm Velvet by consuming too much time, memory, queue space, bandwidth, power, or attention.

## Scenarios

- event flood and heartbeat spam
- queue exhaustion
- reconnect storm after partial failure
- oversized but valid packet stream
- slow consumer holding shared resources
- handmaiden flooding Event Protocol
- node consuming memory or queue capacity
- service repeatedly reconnecting while degraded

## Acceptance

Class 0 and Class 1 services remain responsive. The offender is throttled, shed, or isolated. Court, health, identity, Spine, and receipt paths preserve minimum service. A health event and receipt identify the offender, exhausted resource, start and end times, protection action, dropped work, and recovery result.

Tests must include a clean recovery path and prove that throttling one organ does not silently widen another organ's authority.
