# Minimum Service Classes

Velvet protects work according to consequence, not convenience.

- **Class 0:** emergency and safety-critical service
- **Class 1:** identity, Court, receipts, continuity, and health
- **Class 2:** vehicle state and diagnostics
- **Class 3:** owner interaction and interface
- **Class 4:** comfort and convenience
- **Class 5:** archive, indexing, experiments, and entertainment

## Rules

Class 0 and Class 1 receive protected resources first. Degraded mode sheds work from the highest class number downward. Floods, reconnect storms, slow consumers, and memory pressure may not starve Class 0 or Class 1. Power-aware scheduling uses the same classes. Every shedding decision records affected work, reason, duration, recovery, and receipt ID.

A service class describes protection priority, not authority. Class 0 work still requires its normal identity, Court, safety, and receipt boundaries.
