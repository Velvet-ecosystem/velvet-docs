## Provenance Rule

A finished Velvet doctrine should not hide where an outside idea came from or how it was transformed.

It should also not assign an outside origin merely because similar work exists.

The preferred trail is:

```text
origin state
  -> surviving evidence
  -> direct source claim, when confirmed
  -> limitation
  -> Velvet inference
  -> Adopt / Adapt / Reject
  -> architecture decision
  -> implementation receipt
  -> remaining uncertainty
```

## Confidence States

Backfilled records use:

- `CONFIRMED_EXTERNAL`
- `CONFIRMED_INTERNAL`
- `RECONSTRUCTED`
- `CONVERGENT`
- `UNATTRIBUTED`

Named-reference recovery additionally distinguishes:

- `FOUNDER_CONFIRMED_ORIGIN`
- `SOURCE_MAPPED`
- `CONFIRMED_RESEARCH_REFERENCE`
- `CONFIRMED_ARCHIVE_REFERENCE`
- `NAME_MENTION_ONLY`
- `RECOVERY_CANDIDATE`
- `FICTIONAL_COMPARISON`
- `INTERNAL_DOMAIN_CONCEPT`
- `CONVERGENT_FAMILY`

These labels may change when stronger archive evidence is recovered. Changes should be receipted rather than silently rewritten.
